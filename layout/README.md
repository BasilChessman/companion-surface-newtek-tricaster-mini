# Layout page

`newtek-tricaster-mini-layout.companionconfig` is a one-page Companion export: every TriCaster Mini
control in its grid position, labeled as printed on the panel, with black backgrounds so the panel's
lights stay off. The text colors match the panel's lights (Program red, Preview green, Switcher
Delegate M/E red, the rest white). The SELECT and RATE knob positions already have Rotary Actions
turned on.

Import it on Companion's **Import/Export** page onto an empty page, then use it as a map (or a starting
point) when assigning actions to the panel.
